# مساعد إعداد محاضر المجالس — نسخة HTML

نسخة من أداة «مساعد إعداد محاضر المجالس» (النسخة 8.5) تعمل في ملف HTML واحد على الماك والويندوز، بدون Python وبدون تثبيت.

## الاستخدام

- افتحي الملف `dist/مساعد_إعداد_المحاضر.html` في Chrome أو Edge أو Safari (16.4 أو أحدث).
- في تبويب «الإعدادات» اختاري مجلدات المحاضر المرجعية وقوالب Word. يحفظها المتصفح للمرات القادمة.
- عند إضافة محاضر جديدة إلى المجلد المرجعي اضغطي «تحديث من المجلد».
- المحضر الناتج يُحفظ في مجلد التنزيلات، أو في المكان الذي تختارينه في Chrome وEdge.
- كل المعالجة تتم داخل المتصفح على الجهاز، ولا تُرسل الملفات إلى أي جهة.

## الفروق عن نسخة Python

- المتصفح لا يعيد قراءة المجلدات تلقائيًا، فالتحديث يكون من زر «تحديث من المجلد».
- الاختيارات المتعلّمة تُحفظ في متصفح كل مستخدم، ويمكن نقلها بالنسخة الاحتياطية في الإعدادات، أو باستيراد ملف `reference_learning.json` من النسخة السابقة.
- قراءة PDF تعتمد على pdf.js بدل PyMuPDF وpdfplumber. النتائج قريبة جدًا، وفي ملفات الاختبار كانت أدق في الحروف العربية المتصلة مثل «لا».
- إذا لم يكن في القالب رأس أو تذييل للصفحة، تضيف نسخة Python رأسًا وتذييلًا فارغين، ونسخة HTML لا تضيفهما. هذا لا يغيّر شكل المحضر.

## تعديلات نوفمبر 2026

- **بحث في الأرشيف** في مجلس الكلية ومجلس القسم: بحث حر في كل المحاضر المرجعية بدون تحديد موضوع، مع عرض النص كاملًا ونسخه، أو استخدامه مرجعًا للموضوع المعروض.
- **بدل التميز والتعيين والترقية والمؤتمرات:** عند وجود أكثر من محضر مرجعي من نفس النوع تؤخذ صيغة **أحدث** محضر (مثل عدد المستندات والمرفقات).
- **عنوان موضوع مجلس الكلية** بصياغة محضر الكلية المرجعي، والبيانات المتغيرة (الاسم، الرتبة، القسم، البرنامج...) من محضر القسم. إذا بقي في العنوان أي بيان قديم يُستخدم عنوان محضر القسم كما هو.
- **الرتبة في التوصية** تطابق الرتبة في عنوان الموضوع (ما عدا الترقية لأن فيها رتبتين).
- **الجداول:** الفصل الدراسي في التوصية يؤخذ من محضر القسم الحالي.
- **مجلس القسم:** اسم مقدم الطلب يُستبدل في العنوان والحيثيات والتوصية، حتى لو كُتب الاسم في المحضر السابق بدون فاصلة أو بصيغة «للمحاضرة/».

## البنية

| المسار | المحتوى |
|---|---|
| `src/` | منطق الأداة منقولًا من `core/` و`app.py` و`department_panel.py`، بالأسماء نفسها |
| `vendor/` | fflate 0.8.2 (ملفات ZIP)، pdf.js 3.11.174 (PDF)، شعار الجامعة |
| `build.py` | يجمع كل شيء في ملف HTML واحد داخل `dist/` |
| `tests/` | أدوات الاختبار والمقارنة مع نسخة Python |

## البناء والاختبار

```bash
python3 build.py                        # يبني dist/مساعد_إعداد_المحاضر.html
node tests/smoke.js /tmp                # يفتح الصفحة ويتأكد من عدم وجود أخطاء
```

**المقارنة مع نسخة Python:**

1. انسخي محتوى `tests/python_reference/` إلى مجلد أداة Python.
2. شغّلي اختباراتها مع التسجيل:
   ```bash
   FN_RECORD_OUT=/tmp/rec/calls.jsonl RE_RECORD_OUT=/tmp/rec/re.jsonl python3 -m pytest
   ```
3. أعيدي تشغيل الاستدعاءات المسجلة على نسخة HTML وقارني النتائج:
   ```bash
   node tests/replay_re.js /tmp/rec/re.jsonl
   node tests/replay_fn.js /tmp/rec/calls.jsonl
   ```

`scenario_gen.py` يولّد محاضر ونماذج وملفات Excel واقعية من قالب (`SCEN_TEMPLATE`)، ثم يشغّل مسارات الأداة كاملة عليها.

`tests/e2e.js` يجرب الواجهة نفسها من البداية للنهاية. على Linux شغّليه مع `LANG=C.UTF-8` حتى تُقرأ أسماء الملفات العربية.
